# Фитнес Центр
## Функционал приложения
На форме **"Авторизация"** имеются поля для ввода Логина и пароля, Catpcha, кнопка "Войти" и кнопка для скрытия пароля.
При вводе **user/user** перенаправляет на главную форму. При вводе других данных появляется сообщение об ~~ошибке~~.
На **главной форме** находятся ФИО и номер группы.

## Краткое описание предметной области
Фитнес Центр - место, сочетающее в себе спортивный зал для проведения групповых и танцевальных программ, спортивный зал для игровых видов спорта, тренажёрный зал, плавательный бассейн и другое.
